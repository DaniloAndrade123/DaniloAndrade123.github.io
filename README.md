# 🕸️ Supernatural Web - Saving People, Hunting Things

Página web informativa e interactiva tributo a la serie de televisión **Supernatural** (15 temporadas).

## 🚀 Características
- **Personajes:** Expedientes detallados e interactivos con filtros por categoría (Cazadores, Ángeles/Demonios, Aliados).
- **El Impala '67 ("Baby"):** Especificaciones técnicas y galería de fotos interactiva.
- **Lore & Bestiario:** Información sobre símbolos de protección y criaturas mágicas.
- **Reproductory de Audio:** Reproductor con música de ambiente (*Carry On Wayward Son*).

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3 & Tailwind CSS
- JavaScript Vanilla
